# 🏐 Жеребьёвка команд

Делит список участников на команды случайным образом - с корзинами по уровню, равными составами и разведением девушек по разным командам. Сделано для микс-турниров по волейболу, но подойдёт для любого командного спорта.

Один HTML-файл + CSS + JS, без бэкенда и без сборки. Всё считается в браузере, данные никуда не уходят и сохраняются только в localStorage.

## Возможности

- Количество команд - от 2 до 30.
- Количество корзин - от 1 до 10 (A...J). Корзина = уровень игрока: в A сильные, в B средние, в C новички.
- **Пол определяется по имени автоматически** - словарь русских имён плюс разбор фамилии и отчества. Ничего помечать вручную не нужно.
- **Девушки максимально в разных командах** - галочка. Если девушек меньше, чем команд, каждая попадёт в свою команду; если больше - разложатся максимально ровно.
- **Персональные запреты** - можно указать пары людей, которые не должны оказаться в одной команде.
- Корзины могут быть **разного размера**, и общее число игроков может **не делиться** на число команд - составы всё равно получатся максимально равными (разница не больше одного игрока).
- Проверки: дубли имён, нехватка участников, некратность корзин.
- Экспорт: копирование, TXT, CSV (Excel).
- **Команды выравниваются по силе.** Игрок из первой корзины стоит столько баллов, сколько всего корзин: при четырёх корзинах A - 4 балла, B - 3, C - 2, D - 1. Сумма показывается под составом команды и в сводной таблице. Если сильных не хватило на всех, команда без игрока из A получит лишнего из B, а не из последней корзины.
- Внутри команды игроки идут по корзинам: первым - из A, затем из B, C и так далее.
- Сводная таблица: сколько игроков из каждой корзины и сколько девушек в каждой команде.

## Определение пола

Достаточно вписать имя - `Анна Пахомова`, `Иван Крылов`, `Наташа`. Программа сама поймёт, кто есть кто:

1. словарь имён - полные и уменьшительные (`Екатерина`, `Катя`, `Никита`, `Илья`);
2. отчество - `Ивановна` / `Иванович`;
3. фамилия - `Иванова` / `Иванов`;
4. окончание имени - на `-а` / `-я` обычно женское.

Спорные имена (`Саша`, `Женя`, `Валя`) считаются мужскими, но подсвечиваются - их видно в подсказке под настройками и пунктиром в окне **«Проверить пол»**, где любое имя переключается одним кликом.

Пол можно задать и вручную, прямо в списке:

```
Аня*          - девушка
Саша (м)      - мужчина
```

Понимаются также `(ж)`, `(f)` и `#`.

## Персональные запреты

Пары людей, которым нельзя в одну команду, задаются в `conflicts.js`:

```js
window.CONFLICTS = [
  ['Игрок Один', 'Игрок Два'],
  ['Игрок Один', 'Игрок Три'],
];
```

Порядок слов и регистр не важны: `Иван Петров`, `петров иван` и `ПЕТРОВ ИВАН` - один человек. Одному человеку можно задать сколько угодно запретов. Если развести физически невозможно (людей больше, чем мест), появится предупреждение.

## Как работает алгоритм

1. Считаются целевые размеры команд: `общее / команд`, остаток раздаётся случайным командам. Поэтому составы отличаются максимум на одного игрока.
2. Корзины обрабатываются по очереди A → B → C. Внутри корзины список перемешивается; вперёд идут те, кого сложнее разместить - сначала люди с запретами, затем девушки.
3. Команды, где уже есть конфликтующий игрок, из кандидатов исключаются.
4. Из оставшихся игрок попадает в ту, у которой (в порядке приоритета):
   - меньше всего девушек - только для девушек и только при включённой галочке;
   - меньше всего суммарной силы, то есть команда сильнее всего «недобрала»;
   - меньше всего игроков из этой же корзины;
   - меньше всего игроков вообще.

   При равенстве выбор случайный.
5. **Доводка обменами.** Раздача идёт корзина за корзиной, поэтому к последней корзине свободные места могут остаться всего в одной команде - и две девушки поневоле попадут вместе. Это исправляется обменом: меняются местами два игрока из разных команд, если от этого перекос уменьшается. Размер команд при обмене не меняется никогда, поэтому составы остаются равными, а девушки, сила и запреты выравниваются. Обмены идут, пока результат улучшается.
6. Шаги 2-5 повторяются до 300 раз, из всех вариантов берётся лучший.

Поэтому результат каждый раз разный, но всегда сбалансированный.

## Запуск

Просто откройте `index.html` в браузере. Или локальным сервером:

```bash
python -m http.server 8777
```

## Публикация на GitHub Pages

Залейте файлы в репозиторий, затем в **Settings → Pages** выберите ветку `main` и папку `/ (root)`. Через минуту сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | разметка |
| `style.css` | оформление, светлая тема |
| `conflicts.js` | персональные запреты |
| `gender.js` | словарь имён и определение пола |
| `app.js` | парсинг списков, алгоритм жеребьёвки, экспорт |
