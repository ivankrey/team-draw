🏐 Жеребьёвка команд

Делит участников на команды по корзинам. Составы получаются максимально равными, девушки - по разным командам. Пол определяется по имени автоматически. Всё считается в браузере, данные никуда не отправляются.

Корзина - это уровень игроков. В A - сильные (связки, доигровщики), в B - средние, в C - новички. Из каждой корзины игроки раздаются по командам поровну, а суммарная сила команд выравнивается: игрок из первой корзины стоит столько баллов, сколько всего корзин (при четырёх корзинах A - 4 балла, B - 3, C - 2, D - 1). Сила команды видна под её составом; если составы разного размера, показывается сила на одного игрока. Пол угадывается по имени; если ошиблись - нажмите «Проверить пол» и поправьте, либо поставьте пометку вручную: Аня* - девушка, Саша (м) - мужчина.
